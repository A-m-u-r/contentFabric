# Bug hunt — план исправлений (2026-07-13)

Найдено при ревизии недавней работы (привязка голосов, галерея аватаров,
чистка, ревизия навигации) + более глубокий проход по generate-хендлеру.
Тесты (`tests/test_actor_gallery.py`, 12/12) и `npm run build` — зелёные.
Код пока **не менялся** — это список задач к «фикси».

Приоритет: сначала безопасность (№4–6), потом UX (№1–3).

---

## №4 — Path traversal в `selected_actor_url` (локальная ветка) 🔴
- **Где:** `app.py:4088`
  `src = os.path.join(OUTPUT_DIR, req.selected_actor_url.replace("/videos/", ""))`
- **Проблема:** `../` не отфильтрован. `selected_actor_url = "/videos/../../../etc/passwd"`
  уводит `src` за пределы `OUTPUT_DIR`; файл затем используется как «фото актёра»
  и попадает в рендер/выгрузку → произвольное чтение локальных файлов.
- **Фикс:** нормализовать путь и проверить, что он внутри `OUTPUT_DIR`
  (`os.path.realpath` + `commonpath`), иначе 400. Отклонять `..` и абсолютные пути.

## №5 — SSRF в `selected_actor_url` (http-ветка) 🔴
- **Где:** `app.py:4074-4084`
- **Проблема:** `if selected_actor_url.startswith("http")` → сервер `httpx.get()` на
  ЛЮБОЙ URL, включая внутренние адреса (метадата-эндпоинты, внутренние сервисы).
- **Фикс:** whitelmst разрешённых хостов (ожидаемый S3-бакет/CDN), запрет приватных
  диапазонов и redirects на них.

## №6 — Retry без проверки владельца + traversal в имени каталога 🔴
- **Где:** `app.py:4036-4057`
- **Проблема:**
  1. `retry_job_id` переиспользует/перезаписывает любой существующий `saas_<id>`
     каталог без проверки, что вызывающий им владеет; `owner_user_id`
     переприсваивается новому вызывающему (read-путь `saasshorts_status:4421`
     владельца проверяет — write-путь нет).
  2. `f"saas_{req.retry_job_id}"` с `retry_job_id` вида `x/../../evil` уводит
     `old_dir` за пределы `OUTPUT_DIR` (удаление 0-байтных `*_final.mp4`, запись туда).
- **Фикс:** валидировать `retry_job_id` как UUID (regex), и проверять владельца
  джоба перед переиспользованием.

## №1 — Ручной выбор голоса молча игнорируется при наличии привязки 🟡
- **Где:** бэкенд авторитетно перетирает `req.voice_id` — `app.py:4095-4102`;
  фронт при этом рендерит полностью кликабельный список голосов —
  `dashboard/src/components/SaaShortsTab.jsx:2484-2513` (плашка-предупреждение `:2478`).
- **Проблема:** пользователь может выбрать другой голос, он подсветится как активный,
  но на выходе будет привязанный — футган «поменял, а не поменялось».
- **Фикс:** когда у аватара есть привязка — гасить/дизейблить ручной список
  (или прятать за тумблером «переопределить разово»), чтобы UI совпадал с бэкендом.

## №2 — Аватары из упавших джобов исчезают через час 🟡
- **Где:** `_job_actor_portraits` показывает портрет из любого `saas_*` — `app.py:3247`;
  чистка щадит только каталоги с `*_final.mp4` — `app.py:623`.
- **Проблема:** джоба, успевшая сгенерить `_actor.png`, но упавшая до финального
  видео, попадает в галерею и через `JOB_RETENTION_SECONDS` (1 ч) удаляется —
  аватар пропадает опять (ровно исходный симптом «куда делись аватары»).
- **Фикс:** при создании портрета копировать его в durable-каталог `actor_uploads/`
  (надёжнее всего), либо щадить в чистке каталоги, где есть `*_actor.*`.

## №3 — Мобильная нижняя панель: 8 вкладок в один ряд 🟡
- **Где:** `dashboard/src/App.jsx:836` — `repeat(${navItems.length}, 1fr)` при 8 пунктах.
- **Проблема:** на 375px ~40px на таб, подписи «Проекты»/«YouTube» режутся,
  тач-таргет мелкий.
- **Фикс:** увести редкие вкладки (YouTube-студия, UGC) в «Ещё», либо 2 ряда/скролл.
