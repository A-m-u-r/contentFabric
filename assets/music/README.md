# Фоновая музыка

Треки из этой папки автоматически подмешиваются под озвучку финального ролика
(тихо, с автоприглушением под голос — sidechain ducking).

- Кладите сюда royalty-free треки: `.mp3`, `.m4a`, `.wav`, `.ogg`, `.aac`, `.flac`.
- Трек выбирается детерминированно по названию ролика: один и тот же ролик
  всегда получает один и тот же трек, разные ролики — разные.
- Папка пустая → ролик собирается без музыки (только нормализация громкости).
- Отключить для конкретной генерации: `background_music: false` в конфиге запроса.

`lofi_bed_01.mp3` сгенерирован через ElevenLabs sound-generation (2026-07-10).

`warm_groove_104.wav` и `light_pulse_96.wav` — оригинальные локально
синтезированные инструментальные подложки (2026-10-04). В них нет сторонних
сэмплов, голосов или платных API-вызовов. Темп: 104 и 96 BPM соответственно.

Конкретный трек выбирается через `music_track` (имя файла); `auto` сохраняет
автоматический выбор. `music_volume` задаёт относительную громкость, 0–2,
по умолчанию 1. Каталог и прослушивание: `/api/saasshorts/music-tracks`.
Готовую локальную раскадровку можно пересобрать с другой музыкой через
`POST /api/saasshorts/music`, без повторной генерации озвучки или клипов.
