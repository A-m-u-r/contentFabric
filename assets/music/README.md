# Фоновая музыка

Треки из этой папки автоматически подмешиваются под озвучку финального ролика
(тихо, с автоприглушением под голос — sidechain ducking).

- Кладите сюда royalty-free треки: `.mp3`, `.m4a`, `.wav`, `.ogg`, `.aac`, `.flac`.
- Трек выбирается детерминированно по названию ролика: один и тот же ролик
  всегда получает один и тот же трек, разные ролики — разные.
- Папка пустая → ролик собирается без музыки (только нормализация громкости).
- Отключить для конкретной генерации: `background_music: false` в конфиге запроса.

`lofi_bed_01.mp3` сгенерирован через ElevenLabs sound-generation (2026-07-10).
